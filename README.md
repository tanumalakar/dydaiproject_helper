# DYD AI Project Student Support Chatbot 🤖

An AI-powered student support chatbot developed for the DYD AI Project.

## 🌐 Live Website

https://tanumalakar.github.io/Works_n_Projects/

## 📌 Project Overview

This project is designed to help students get information about the DYD AI Project and AI Batch admission process.

Students can ask questions in:

- Bangla
- English
- Banglish

The chatbot provides simple and helpful answers related to the project, admission, courses, eligibility, application process, and other student queries.

## ✨ Features

- AI-powered student support chatbot
- Bangla, English, and Banglish language support
- AI Batch admission information
- Course and program information
- Student-friendly interface
- Responsive website design
- Chatbase AI chatbot integration
- Easy access to the official admission page

## 🤖 Chatbot Platform

The chatbot is powered by Chatbase AI.

Chatbase is used to provide automated answers to student questions based on verified information from the official DYD AI Project website and knowledge base.

## 🎯 Project Objectives

- Help students quickly find admission information
- Reduce repeated student queries
- Provide 24/7 basic support
- Make information accessible in multiple languages
- Improve the student admission experience

## 🚀 How to Use

1. Visit the live website.
2. Click on the chatbot icon.
3. Ask a question in Bangla, English, or Banglish.
4. Read the chatbot's response.
